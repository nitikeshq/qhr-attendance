# QHR Attendance Mobile

Expo SDK 54 employee client for the unified QHR backend.

## Run

```powershell
npm install
npm start
```

The Android emulator defaults to `http://10.0.2.2:5001`; iOS and web default to `http://127.0.0.1:5001`. For a physical phone, set `EXPO_PUBLIC_API_URL` to the backend's LAN URL before starting Expo.

Demo login: company `TESTCO`, employee `EMP001`, passcode `1234`.
